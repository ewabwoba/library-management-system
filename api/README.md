# NestJS Backend

A backend application built with [NestJS](https://nestjs.com/), a Node.js framework for building scalable server-side applications using TypeScript.

## Tech Stack
- Node.js
- NestJS
- TypeScript

## Installation

```bash
npm install
```

## Running the Application

```bash
# Development
npm run start

# Watch mode
npm run start:dev

# Production
npm run start:prod
```

## Testing

```bash
# Unit tests
npm run test

# End-to-end tests
npm run test:e2e

# Test coverage
npm run test:cov
```

## Project Structure

```text
src/
```
